# iM 이룸 — IDEATION

버전: 0.2 · 갱신일: 2026-09-20

이 문서는 기획 배경·가설·결정 이유·열린 질문을 기록한다. 제품 요구사항은 [PRD.md](PRD.md), 구현 계약은 [TRD.md](TRD.md)를 기준으로 한다.

## 1. 핵심 질문

“청년이 재무 목표를 세운 뒤, 상황이 바뀌어도 그 목표를 계속 관리받게 하려면 무엇이 필요한가?”

교육이나 상품 정보를 전달하는 것에서 출발하기보다, 고객이 목표를 유지하는 데 필요한 반복적인 판단과 조정을 제품의 중심에 둔다.

은행 관점에서는 청년 고객과의 지속적인 접점, 목표에 맞는 상품 이용, 상담 자원의 효율적 배분이 가치 가설이다. 이는 iM뱅크가 공식적으로 밝힌 사업 의도로 확인된 내용이 아니다.

## 2. 기획의 변화

| 이전 탐색 | 현재 방향 | 설계에 미치는 영향 |
|---|---|---|
| 청년재무주치의 | iM 이룸 | 치료·진단의 비유보다 목표 달성과 지속 관리에 초점 |
| AI가 재무 조언을 생성 | 계산·규칙 엔진이 계획을 산출하고 AI가 설명 | 숫자 재현성 확보, AI의 역할을 좁고 명확하게 정의 |
| 실시간·상시 변화 감지 | 동의일 기준 월 1회 고객 데이터 수집 | 월간 스냅샷 비교; 실시간으로 알고 있다는 표현 제거 |
| 실제 마이데이터 연동 | API 응답 구조를 참고한 합성 데이터 재현 | 외부 연결 없이도 상태 변화·재설계 검증 가능 |
| 추천 후 종료 | 승인·모의 실행·다음 월 피드백 | 한 번의 추천보다 반복 관리의 차이를 시연 |

## 3. 제품 가치 가설

### H1. 정보 부족보다 실행 계획의 부재가 중요한 문제일 수 있다
### H2. 변화의 이유를 설명하면 조정안을 이해하기 쉬워질 수 있다
### H3. 위험 사례를 요약하면 상담 준비 부담을 줄일 수 있다
### H4. 생성형 AI의 가치는 숫자 계산보다 설명과 문서 처리에 있을 수 있다

### H5. 한 번의 추천보다 목표 달성까지 이어지는 관리 순환이 유지 행동에 더 도움이 될 수 있다

## 4. 최종기획서에서 확정된 제품 관점

- 1차 대상은 대구 거주 만 19~34세 사회초년생이다.
- 진단은 최근 거래를 급여·고정·변동·비정기 지출로 나누고 월 저축 여력과 새는 돈 후보를 찾는다.
- 정책은 포트폴리오 밖의 알림이 아니라 가용자금과 목표 달성 시점 계산에 반영한다.
- 반복 계산과 점검은 시스템이 맡고, 연체·다중채무 등 판단과 공감이 필요한 위험은 상담사에게 연결한다.
- 목표를 달성하면 보증금·결혼자금·주택 마련 등 다음 목표로 관리가 이어진다.
- 추천 품질만이 아니라 순자산 변화, 만기 유지, 지원제도 수혜, 리볼빙·카드론 잔액 변화를 장기 연구 지표로 본다.

최종기획서의 2년 순자산 증가율 44.8%, 증가 소득의 저축·투자 배분 61.1%, 채무조정 참여자 부채 감소 19%는 외부 사례 근거이다. iM 이룸의 예상 성과나 인과효과로 사용하지 않는다.
